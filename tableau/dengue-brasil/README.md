# Dengue no Brasil — Análise de Casos (1990–2014)

**Tableau | Análise Exploratória | Visualização Geográfica e Temporal**

## Visão geral

Dashboard desenvolvido durante a pós-graduação em Ciência de Dados e Mercado Financeiro (CDMF), na XP Educação, para explorar a evolução e a distribuição de registros de dengue no Brasil entre **1990 e 2014**.

A análise reúne indicadores nacionais, comparações regionais, distribuição geográfica por estado e evolução anual dos registros. Os filtros do painel permitem aprofundar a investigação de regiões específicas.

## Indicadores e análises

- **Total de casos:** indicador agregado para o período selecionado.
- **Distribuição regional:** comparação entre Sudeste, Nordeste, Centro-Oeste, Norte e Sul.
- **Análise por estado:** mapa temático com quantidades e intensidades de cor.
- **Evolução anual:** série temporal para identificar variações e períodos com maior número de registros.
- **Exploração interativa:** seleção de uma região para atualizar os indicadores, o mapa e a série temporal.

## Estrutura do dashboard

O projeto foi desenvolvido no **Tableau** e contém um painel principal composto por **cinco planilhas**: `Linha`, `Mapa`, `Pizza`, `Regiao` e `Total de casos`.

Nas capturas apresentadas, o indicador nacional totaliza **9.216.989 casos** no intervalo exibido, enquanto a seleção da **Região Sudeste** apresenta **4.223.725 casos**. Os números ilustram o conjunto de dados utilizado no exercício, não estimativas epidemiológicas atuais.

## Aplicações

Análise exploratória de séries históricas, comparação regional, distribuição espacial de indicadores e comunicação visual de informações para apoio à investigação de dados.

**Tecnologias e recursos:** Tableau, dashboard interativo, gráficos temporais, mapa temático e filtros por região.
